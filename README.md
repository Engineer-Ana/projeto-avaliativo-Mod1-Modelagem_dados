# Projeto-avaliativo-Mod1-Modelagem_dados
Atividade avaliativa do Módulo 1 do curso 'Carreira Tech - Trilha Análise de Dados | Modelagem de Dados', etapa profissionalizar do programa de qualificação tecnológica do governo de Santa Catarina, em parceria com o Senai/SC. Neste projeto, realizei a extração de dados de RH com SQL e a análise estatística exploratória utilizando Python e Pandas.
